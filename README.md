# ft_printf с бонусами

Полная обязательная часть и бонусные флаги School 42.

Поддерживаются `%c`, `%s`, `%p`, `%d`, `%i`, `%u`, `%x`, `%X`, `%%`;
флаги `-`, `0`, `#`, `+`, пробел; числовая ширина и точность (`%#08x`, `%+10.5d`, `%-12.3s`).
`-` отключает заполнение нулями; точность отключает флаг `0` для чисел;
`+` имеет приоритет над пробелом; `#` добавляет префикс только ненулевому hex.

## Сборка

```sh
make
make bonus
make clean
make fclean
make re
```

Оба варианта собирают `libftprintf.a` с поддержкой бонусов. Повторный `make`
не пересобирает библиотеку без изменений. Подключение:

```c
#include "ft_printf.h"

int main(void)
{
    ft_printf("Number: %+08d, hex: %#x\n", 42, 255u);
    return (0);
}
```

```sh
cc -Wall -Wextra -Werror main.c -L. -lftprintf -o demo
```

## Проверки и границы

5149 сравнений с системным printf на macOS: вывод (включая нулевой символ)
и число напечатанных байтов совпали. AddressSanitizer и UndefinedBehaviorSanitizer
ошибок не обнаружили. Это не заменяет проверку по subject вашего кампуса.

`%p` для NULL выводит `0x0` (поведение macOS). `%s` для NULL использует `(null)`;
эти случаи у системных библиотек различаются. NULL-формат, неизвестная конверсия
и незавершённый `%` возвращают -1. Ошибки write возвращают -1.
Флаги используйте только с соответствующими им конверсиями C printf.
Звёздочка ширины/точности, модификаторы длины и float не реализованы.
